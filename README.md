# GhoulKing — Official Website

The official website for **GhoulKing**, an independent gaming tournament-organizing brand founded by **Victor Rodriguez**.

GhoulKing focuses on organizing competitive gaming events, beginning with Dance Dance Revolution and rhythm games, with plans to expand into fighting-game tournaments and gaming venue partnerships throughout New York City.

## About

GhoulKing is dedicated to creating organized, fair, and welcoming competitive gaming experiences.

The website showcases tournament history, event documentation, organizing capabilities, and opportunities for venue collaboration.

## Local Development

Install dependencies:

```bash
bun install
```

Start the development server:

```bash
bun run dev
```

Build for production:

```bash
bun run build
```
